# Parking Mkononi Documentation

These documents describe the implemented Parking Mkononi Smart Parking System.

1. `01_Requirements_and_System_Design.docx` — client requirements, TOR analysis, modules, system flow and technologies.
2. `02_Algorithms_and_Data_Structures.docx` — algorithms, pseudocode-style steps, structures and complexity.
3. `03_Implementation_Storage_and_Testing.docx` — implementation structure, storage design, tariff and testing evidence.
4. `04_User_Guide.docx` — how to run and use the system.

The documents are intentionally separated so that each part can be referenced independently in the coursework submission.
